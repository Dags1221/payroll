EMPLOYEE ATTENDANCE MONITORING AND PAYROLL MANAGEMENT SYSTEM
Academic Activity Prototype

HOW TO RUN
1. Open index.html in Google Chrome, Microsoft Edge, or another modern browser.
2. No installation, database, internet connection, or server is required.
3. Use the sidebar to demonstrate the modules.
4. Data changes are saved in the browser's localStorage.

DEMO MODULES
- Dashboard
- Employee Information Management
- Employee Attendance Monitoring
- Leave Request and Approval Management
- Overtime and Compensation Management
- Payroll Processing
- Employee Benefits Management
- Cost Center Management
- Reports and Analytics
- Printable Payslip

IMPORTANT
This is a front-end prototype for an academic activity. Payroll tax and deduction figures are simplified sample values and are NOT official payroll/tax calculations.
All data is demo data and is stored locally in the browser.
